# ショート動画案

縦型 15〜45秒。1本1テーマ。最後にアプリへ誘導（「この続きはアプリで毎日5分」）。

## シリーズ案

| シリーズ | 尺 | 中身 |
|---|---|---|
| 3秒クイズ | 15秒 | 問題 → 3秒カウント → 答え → 一言解説 |
| 語呂合わせ1本勝負 | 20秒 | 年号・順位を1つだけ、語呂を絵と音で |
| どっちがどっち？ | 30秒 | 間違えやすい2つを並べて違いを1点だけ言う |
| 地図でズーム | 30秒 | 日本地図から県・地形にズームして特徴3つ |
| 1分でつながる歴史 | 45秒 | 出来事Aがなぜ出来事Bにつながるか（因果） |
| 入試に出たグラフ | 30秒 | 実際によく出る形式のグラフを読み解く |
| 今週の時事 | 45秒 | ニュース1つ → 入試で問われそうな知識 |
| ボソボソだけ | 20秒 | ボソボソタイムだけを切り出した復習版（寝る前に聞く用） |
| 人物ひとこと | 20秒 | 歴史人物の「これだけ覚えれば点が取れる」1つ |

## 台本の型（30秒・サッ記マン版）

キャラ設定は [character.md](character.md)。通常モード → ボソボソタイムの切り替えを毎回入れる。

```
0〜3秒   フック（通常）：「サッと記憶、サッ記マン！」＋今日のお題を画面いっぱいに
3〜15秒  唱える（通常）：BPM130の4拍子で、語呂・並びを元気に2回
15〜25秒 ボソボソタイム：同じ内容を低い小声でゆっくり1回。テロップは大きく
25〜30秒 誘導（通常）：「もう一回、一緒に！ 続きはアプリで毎日5分」
```

- 唱える部分は前半と後半で一字一句同じにする（復唱で覚えさせるため）
- 台本の読みはかな表記。地名・人名の読みは投稿前に確認する

## 運用

- 動画1本 = アプリの問題数問に対応させる（同じ問題データから作る）
- 週◯本のペースは未定（[open-questions.md](open-questions.md)）
- 反応が良かったテーマはアプリの出題優先度を上げる
