# サッ記マン（さっきまん）
## 中学受験・社会の暗記ヒーロー

**「サッと記憶、サッ記マン！」**

リズム・語呂合わせ・繰り返しを使って、社会の知識を「思わず口に出したくなる言葉」にするヒーロー。

元気いっぱいに唱えたあと、突然ささやき声の**「ボソボソタイム」**に入り、同じ内容をゆっくり復唱する。この声とテンポの切り替えが、サッ記マン最大の個性。

### 基本設定

- **名前：** サッ記マン
- **読み方：** さっきまん
- **肩書き：** 中学受験・社会の暗記ヒーロー
- **担当：** 地理・歴史・公民を中心とした社会の学習
- **使命：** 覚えることが多くて困っている子どもを、声とリズムで応援する
- **決めぜりふ：** 「サッと記憶、サッ記マン！」

### ２つの表現モード

| モード | 声・テンポ・振る舞い |
|---|---|
| **通常モード** | 超ハイテンション。ハキハキと歯切れよく、元気に声を張る。基本はBPM130程度の4拍子。言葉のまとまりごとに短く息を継ぎ、決めぜりふを力強く聞かせる。 |
| **ボソボソタイム** | 突然、マイクに近づいたような低いささやき声になる。落ち着いた速さで、同じ内容をゆっくり繰り返す。小声でも、一つ一つの言葉は明瞭に聞かせる。 |

### 得意な教え方

- **リズムで並べる**  
  都市名・人物名・時代の順序などを、口ずさみやすいまとまりにする。

- **語呂でつなぐ**  
  「かわ・さが・はま・さかい・きたきゅう！」のように、短い合言葉を作る。

- **同じ言葉を復唱する**  
  前半に元気よく唱えた内容を、後半のボソボソタイムでもう一度聞かせる。

### 性格の方向性〈ここからは補足案〉

- **明るく熱血。** 教えることも、一緒に唱えることも大好き。
- **少しお調子者。** 大げさな決めポーズや、突然の小声で楽しませる。
- **子どもに寄り添う。** 覚えられなくても責めず、「もう一回、一緒に！」と誘う。
- **知識を大切にする。** 楽しい言い方を考えながら、内容や読み方の正確さにも気を配る。

### 制作するときの約束

- 地名・人名・社会用語の読み方を確認する。
- 歌詞や読み上げ台本は、誤読しやすい漢字・数字をかな表記にする。
- リズムに合わせるときも、言葉を詰め込みすぎず、聞き取りやすさを優先する。
- 語呂合わせによって、元の知識や意味が変わらないようにする。

### まだ決まっていない設定

外見・衣装・配色・年齢・道具・誕生の物語は未設定。
現時点では、**声とリズム、そして「ボソボソタイム」がキャラクターの中心**となっている。
