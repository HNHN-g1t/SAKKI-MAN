# 記憶アプリ案

## コア：1日5分の「忘れかけ」出題

- 間隔反復（正解したら3日後→1週間後→1か月後に再出題、間違えたら翌日）
- 毎日の出題数は固定（例：20問）。「今日の分が終わった」が見える
- 苦手は自動で増える、得意は自動で減る。子どもは何も設定しない

## 出題形式（社会ならではのもの）

| 形式 | 分野 | 例 |
|---|---|---|
| 一問一答 | 全分野 | 「日米修好通商条約を結んだ大老は？」 |
| 地図タップ | 地理 | 白地図で「りんご生産1位の県」をタップ |
| 並べ替え | 歴史 | 4つの出来事を古い順に並べる |
| 線つなぎ | 歴史・公民 | 人物 ↔ 出来事、条約 ↔ 相手国、省庁 ↔ 仕事 |
| グラフ読み | 地理 | 生産量の円グラフから県・品目を当てる（入試頻出） |
| 雨温図 | 地理 | 雨温図を見て都市を4択で選ぶ |
| 地形図 | 地理 | 地図記号・等高線の読み取り |
| 一行記述 | 全分野 | 「なぜ〇〇か」を20字で。模範解答と自己採点 |

## 覚え方のサポート

- 語呂合わせカード（年号・統計順位）。自分で作った語呂も登録できる
- 「つながり」表示：1問解くと関連事項が横に出る（例：鎌倉幕府 → 御恩と奉公 → 元寇 → 徳政令）
- 間違えやすいペアを並べて出す（例：楽市・楽座／太閤検地、親藩／譜代／外様）
- 年表・地図上に「覚えたもの」が色付きで埋まっていく

## 続ける仕掛け

- 連続日数ではなく「覚えた数」を主役にする（休んでもゼロに戻らない）
- 都道府県・時代ごとにコンプリートバッジ
- 保護者向け：今週の正答率・苦手分野だけを1画面で

## 時事

- 入試前の秋〜冬に「今年の時事」パックを追加（ニュース→関連する教科書知識の順で出題）

## MVPに絞るなら

1. 一問一答 ＋ 間隔反復
2. 地図タップ（都道府県）
3. 並べ替え（歴史）

問題データは「分野／単元／問題／答え／解説／関連ID」の表で持ち、動画とも共有する。
