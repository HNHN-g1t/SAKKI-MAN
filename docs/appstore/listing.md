### 説明
```
サッ記マン 日本地図ドリルは、中学受験の社会（地理・歴史）を、日本地図の上で覚えるドリルです。
覚えることは、いつも「場所」とセット。名前を見て地図をタップしたり、光った場所の名前を4択で答えたりしながら、地図ごと頭に入れます。

■ 地理コース
・県名タップ／県のシルエット（全国からランダム10・20・30・オール47）
・県庁所在地／名前ちがいの18都道県／政令指定都市
・山地・山脈、川、平野、盆地、湖、火山、島、半島、海岸・湾、海流、地形の用語、海なし県
・気候区分と雨温図
・農林水産業・工業、No.1の県（統計の1〜3位）、県の特色、総合問題

■ 歴史コース
・歴史の場所、国宝・世界遺産

■ 学び方
・目のボタンを押している間だけ県名が出ます（使った問題は王冠マークに数えません）
・正解でも自動で進みません。解説を読んでから「つぎへ」
・まちがえた問題は「苦手だけドリル」で、翌日・3日後・7日後に復習
・最初から全部ノーミスで「パーフェクト！」、全部に王冠マークでコースマスター
・ピンチで地図を拡大できます

■ そのほか
・ライト・ダークの切りかえ、BGM・効果音のオンオフ
・インターネットにつながなくても使えます
・ログイン不要。記録はiPhoneの中だけに保存し、外へ送りません
・記録をバックアップ（1行の文字にしてコピー）して、機種変更のときに戻せます
・統計の問題は、国や県の資料で確かめた年と出典をもとにしています
```
