# SAKKI-MAN

中学受験の **社会** に特化した記憶アプリ ＆ ショート動画のアイデア置き場。

## アプリ（スマホで開く）

- [日本地図タップクイズ](https://sakki-man.vercel.app/japan-map-quiz/) … 出された県を地図でタップ（[仕様](apps/japan-map-quiz/HANDOFF.md)）

## 前提

- 対象：小4〜小6の中学受験生（と保護者）
- 範囲：地理・歴史・公民・時事
- 方針：動画で「おっ」と思わせて、アプリで「定着」させる
