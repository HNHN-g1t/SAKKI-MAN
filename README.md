### 何のためのアプリか

- **中学受験の社会を、地図の上で覚える。** 「サッと記憶のサッ記マン」。県名・県庁所在地・地形・気候・産業も、歴史の出来事や国宝も、いつも「日本地図のどこか」とセットで覚える
- **答えはいつも「場所」と結びつける。** 問題では答えの場所を光らせ、答えたあとも地図に正解の県・場所を残す。名前だけを覚えるクイズにはしない
- **モードは中学受験だけ。** 学年ごとのモードはやめて、入試に出る範囲にしぼった

### 学び方の決まり

- **ノーミスを目標にする。** 合言葉は「県名なしの日本地図でノーミスクリアをめざそう！」。目のボタン（押している間だけ県名）を使った正解は記録に残すが、👑には数えない
- **ステージ制で少しずつ。** 地方や時代ごとに4〜11問の短いステージ。ステージ👑 → コースの👑マスター → 次のコースが開く
- **正解でも説明を読ませる。** 答えたら自動では進まず、「つぎへ」を押すまで解説を表示する
- **パーフェクトとクリアを分ける。** まちがえた問題だけのやり直しを全部正解しても「クリア！」。最初から全部ノーミスのときだけ「パーフェクト！」
- **やり直しやすく、ズルはしにくく。** 途中でやめるときは確認する。DBG（暗証番号つき）のお試し記録と本当の記録はまぜない

### 正確さの決まり

- **子どもがまちがった知識を覚えないことを最優先にする。**
- 統計の問題（産業）は、国や県の資料で1位を確かめ、統計の年と出典を問題データに持たせる。年によって1位が入れかわるものは年を明記するか、出題しない（[出典一覧](apps/japan-map-quiz/INDUSTRY_SOURCES.md)）
- 表記は時代に合わせる（例：豊臣秀吉の城は「大坂城」）
- 地図に置く印（県庁・政令指定都市・歴史の場所・国宝）は、すべて自分の県の形の内側にあることを機械で確かめる。簡略化した地図で外に出る場所は、近くの陸へ少し寄せてコードに理由を書く

### 見た目の趣向

- **キーカラーは黄色（#FED003）と墨（#282727）。** 黄色の上の文字は必ず墨。黄色は「選んでいる・正解・押すボタン・見出しの帯」にだけ使う
- **ライトは真っ白にしない。** 目にやさしいライトグレー（#EEEDEA）。地図の陸だけ少し明るく残す。ダーク・ライトは切りかえボタンで選べ、選んだほうを覚える
- **文字は読みやすさ優先。** 本文は BIZ UDPゴシック、見出しは Dela Gothic One。言葉の途中で改行しない（「・」のあとでだけ折る、1行に入るなら折らない）
- **ふりがなは漢字の上に、漢字だけに。** ひらがな・カタカナには付けない。よみが長いときは字を小さくして漢字の幅に収める
- **絵文字は使わない。** 王冠・矢印・○×などはシンプルな SVG のアイコンにして、スタイリッシュにそろえる
- **画面はスマホ1枚に収める。** 上に帯、まん中に大きな地図、下に問題のウインドウ。答える前と後でウインドウの高さを変えない。iPhone の上のぼかしを避けるため、上の帯は画面に貼りつける作り
- **地図を主役にする。** 「つぎへ」は地図の上の黄色い ▷（ななめの光がキラッと横切る）。押せる範囲は三角の中だけ

### 気持ちよさの趣向

- **正解は「シュパーン」と気持ちよく。** 黄色い花火のパーティクルと、駆け上がる音＋和音。ステージクリア・パーフェクトは花火を何発も、👑マスターは最初の一度だけお祝い画面とファンファーレ
- **音はひかえめ。** 全体の音量はおさえめにして、BGM と効果音は別々にオンオフできる
- **ごほうびは「楽しい」だけでなく「覚えられる」ものにする。** 試作したご褒美ゲームは、知識につながらなかったので外した（次の案は [HANDOFF](apps/japan-map-quiz/HANDOFF.md) に残してある）

### 作り方の決まり

- 画面とプログラムは1つの HTML ファイル（`src/template.html` → `tools/build.py` で `index.html`）。BGM だけ別ファイル（`bgm/` の mp3 2曲）。JavaScript のライブラリは使わない（文字は Google Fonts）
- 記録は端末の中（localStorage）に自動保存。古い記録は形が変わっても引きつぐ
- 色は `:root` とダークの2か所の変数でだけ決める。文字と背景のくらべやすさは `tools/contrast.py` で確かめる
- 変更したら375px幅のスマホ表示で画面を撮って確かめ、main に push する（スマホで見られないと終わっていない）
