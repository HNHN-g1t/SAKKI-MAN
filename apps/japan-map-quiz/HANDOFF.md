# 日本地図タップクイズ 引継ぎ資料

中学受験（社会・地理）向けに、息子さんが毎日遊べる地図クイズ。
出された県を日本地図でタップして答える。claude.ai のチャットで v4 まで作成し、以降は Claude Code で更新する。

- 現行版（claude.ai アーティファクト）: https://claude.ai/artifact/VcLggsEPp1r5scBSFnbym8
- 対象端末: スマホ・タブレットのブラウザ（PCも可）
- 形式: HTML 1ファイル完結（ビルド不要・外部通信は Google Fonts のみ・地図データ埋め込み）

## 作業ルール（ユーザーの方針）

- 質問されたら、まず質問に答える。制作・変更は、必要なら進めてよいか確認してから着手する。
- 確率・集計など数値が絡むものは、必ずコードを実行して結果を出す（暗算・推定で答えない）。

## ファイル構成

```
japan-map-quiz/
├─ index.html          完成品（tools/build.py の出力。直接編集しない）
├─ src/template.html   本体（HTML・CSS・JS）。__PATHS__ に地図データが入る
├─ data/
│   ├─ paths.json      県のSVGパス（build_paths.py の出力）
│   └─ jp_raw.json     Natural Earth から日本47都道府県だけ抜き出した元データ
└─ tools/
    ├─ extract.py      元データ → jp_raw.json
    ├─ build_paths.py  jp_raw.json → paths.json（投影・簡略化・島の取捨・沖縄の枠用コピー）
    ├─ preview.py      paths.json を PNG で確認（matplotlib）
    └─ build.py        template.html ＋ paths.json → index.html
```

### 更新の手順

- 画面・動きの変更: `src/template.html` を編集 → `python3 tools/build.py`
- 地図の形・島・沖縄の枠位置の変更: `tools/build_paths.py` を編集 → `python3 tools/build_paths.py data/jp_raw.json 0.012` → `python3 tools/build.py`
  - 第2引数は簡略化の強さ（度）。小さいほど細かく重くなる。現在 0.012 で地図データ約 42KB
- 元データから作り直す場合（通常は不要）:
  1. `https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson`（約40MB）を取得
  2. `python3 tools/extract.py <そのファイル>`
  3. `pip install shapely`（build_paths.py が使う）

地図データは Natural Earth（パブリックドメイン）1:10m admin-1。

## 座標系

`build_paths.py` と template 内の `toXY()` は同じ投影を使う。変えるときは両方そろえる。

```
x = (経度 - 128) × cos(36°) × 60
y = (45.8 - 緯度) × 60
```

`paths.json` の1要素:

| キー | 内容 |
|---|---|
| `c` | JIS都道府県コード 1〜47 |
| `d` | SVGパス（実際の位置） |
| `l` | 県名ラベルの位置（一番大きい島の内側の点） |
| `b` | ズーム用の範囲 [x0,y0,x1,y1]。一番大きい島だけで計算（離島で範囲が広がらないように） |
| `di` `li` `bi` | 沖縄（c=47）だけ。左下の枠に置くコピーのパス・ラベル位置・範囲 |

### 島の取捨（`keep()`）

- 東京: 小笠原（緯度33°未満）を除外。伊豆諸島は残す
- 鹿児島: 奄美を含めすべて残す（九州・沖縄にズームしたとき正確な位置関係になるように）
- 沖縄: 本島周辺のみ（経度126.5〜129°）。宮古・八重山・大東は除外
- 面積 0.0015 未満の小島は除外（本体は必ず残す）

## 決まっている仕様

### 画面

- 上: 問題バー（ホームではタイトル）／中: 地図／下: シート（ホームでは地方ボタン、クイズでは進み具合と正誤）
- 白地図ふう: 海は青、陸は白、県境は黒線。ホームの自由閲覧では地方ごとに淡い色分け
- フォント: Dela Gothic One（見出し）＋ Zen Maru Gothic（本文）。ライト／ダーク両対応（CSS変数）

### 目ボタン（右下）

- 初期状態は県名なし。押している間だけ県名を表示し、離すと消える（pointerdown / pointerup）
- クイズ中に押すと、その問題は「ヒントあり」扱い。正解でも連続正解（コンボ）が切れ、ベスト記録にはヒントなし正解だけ数える
- 地図上の県名は「県」「府」「都」を省いた短縮形（北海道はそのまま）

### ぜんこくボタン（地図の左上）

- いつ押しても全国表示（`FULL` 範囲）に戻る。クイズ中も使える

### 虫眼鏡（地方ズーム）

- 各地方の境目付近に置き、タップでその地方へズームする（`ZOOM_SPOTS`、緯度・経度で指定）
  - 東北: 秋田・岩手県境／九州: 熊本・大分・宮崎の境 など
- 画面上で常に同じ大きさ（ズームに合わせて逆スケール）
- 表示するのはホームと全国クイズ。地方クイズ中は答えを隠してしまうので非表示。かなり拡大したとき（`view.w < 330`）も非表示

### 沖縄の表示切り替え

- 全国表示: 九州の左下に移した「枠内の沖縄」を表示し、破線の仕切り線で区切る
  - 仕切り線は左へ水平 → 下へ → 斜め → 下へ、の折れ線。左端と下端は座標 ±100000 まで伸ばしてあり、どれだけ拡大・移動しても画面外へ見切れる
  - 破線の間隔は拡大しても変わらない（`vector-effect: non-scaling-stroke`）
  - 沖縄のまわりの四角い枠は付けない（ユーザー指示で削除済み）
- 九州・沖縄にズーム: 実際の位置の沖縄を表示（奄美も含めて正確な位置関係）
- 判定（`apply()` 内）: `view.w > 700`、または実際の沖縄が画面外なら枠内の沖縄を出し、実際の沖縄は隠す。両方が同時に見えることはない
- 正誤の色は MutationObserver で実際の沖縄から枠内のコピーへ自動で反映。どちらをタップしても県コード 47

### クイズ

- 出題範囲（`AREAS`）: 北海道・東北／関東／中部／近畿／中国／四国／九州・沖縄／全国（応用編）
  - 北海道は1県だけになるので東北とまとめた。三重は近畿
- 地方を選ぶと、その地方にズームし、範囲外の県は灰色でタップ無効
- 正解: 緑に光って薄緑で残る → 1.3秒で次へ。2問以上連続でコンボ表示
- 不正解: タップした県が赤くなり県名タグを表示。正解の県が点滅し、薄赤で残る →「つぎへ」で次へ
- 結果: 正解数／ヒントなし正解数／最高コンボ。まちがえた県だけで再挑戦できる
- 効果音: Web Audio の短い音。上部ボタンでオン・オフ

### 保存（`localStorage` キー `jmq-v1`、この端末だけ）

```js
{ best: { [地方id]: ヒントなし正解数 }, miss: { [県コード]: まちがえた回数 }, mute: boolean }
```

`miss` は記録しているが、まだ画面では使っていない（下の「次にやること」参照）。

## 拡張のしかた

### 問題の種類を足す（分野別）

`QUIZ_TYPES` に追加する。`make(codes)` は問題の配列を返す。`answers` に複数の県を入れられる。

```js
QUIZ_TYPES.apple = {
  title: "りんごの生産",
  make: () => [
    { text: "りんごの生産量 <em>1位</em>は？", sub: "", answers: [2], explain: "青森県が全国の約6割" },
  ]
};
// 開始: startQuiz(AREAS.find(a => a.id === "zenkoku"), [], "apple")
```

現状の制約（拡張時に直すところ）:

- `startQuiz(area, codes, typeId)` の `codes` は県名あて用。分野別では `make()` が `codes` を使わない設計にしてよい
- 複数正解（漁獲量の上位3県を全部タップ、など）は、今は `answers` のどれか1つで正解になる。「全部タップ」にするなら `handleTap` に正解済みの管理を足す
- 分野別の問題を選ぶ画面はまだない（ホームは地方ボタンだけ）
- 統計の数値（生産量・順位）は年で変わる。問題に入れるときは出典と年を確認し、`explain` に年を入れる

### 県データに項目を足す

`PREFS[i].facts` が空オブジェクトで用意してある（例: `facts.apple = 1`）。

### 地図API（`window.JapanMap`）

| 関数 | 用途 |
|---|---|
| `onPrefectureTap(cb)` | 県タップ時に県コードを渡して呼ぶ |
| `setPrefectureColor(code, color)` | 県の色を直接変える |
| `resetColors()` | 色と状態クラスをすべて戻す |
| `highlightPrefecture(code)` | 点滅させる |
| `zoomToPrefecture(code)` | その県へズーム |
| `getPrefecture(code)` | 県データを返す |

## 実装メモ（はまりどころ）

- 表示範囲は `view = {x, y, w, h}` を SVG の viewBox に入れて動かす。`h` は常に地図枠の縦横比に合わせる（`setView`）
- 範囲合わせ（`fitLater`）は、シートの中身を描いた後に2フレーム待ってから行う。先に合わせると、シートで地図枠が縮んで日本がはみ出す
- 地図枠の大きさが変わったら `ResizeObserver` で中心と縮尺を保って合わせ直す
- `fitBox` は下側を少しあけて合わせる（右下の目ボタンに地図がかからないように）
- タップとドラッグの区別: 10px 以上動いたらドラッグ扱い。2本指はピンチ。PC はホイールでズーム
- 小さい県（香川・東京・大阪など）: 地方クイズでは自動ズームで十分大きくなる。全国クイズではピンチで拡大して押す
- 東京の「県庁所在地」は `東京（都庁は新宿区）` と表示

## 次にやること（候補）

1. 県名と県庁所在地名がちがう県の問題（愛知→名古屋など）。受験頻出で、今の地図のまま作れる
2. まちがえた県の復習（`miss` を使い、翌日・3日後・1週間後に再出題）
3. 分野別の問題（りんご・みかん・漁獲量など）と、それを選ぶホーム画面
4. 全国表示で 近畿・中国・四国 の虫眼鏡が近く、押しにくければ小さくするか地方名ラベルにする
5. 沖縄の仕切り線の上端は「左へ水平に伸ばす」形にしている。ユーザーが「真上に伸ばす」形を望む場合は `#insetg` の `polyline` の座標を変える

## 動作確認

ブラウザで `index.html` を開く。自動確認する場合の観点:

- 県が47個描画され、コードの重複がない（`document.querySelectorAll('.pref').length` は沖縄の枠用コピーを含めて 48）
- スマホ幅（375〜390px）で地図が切れない
- 九州・沖縄クイズで実際の位置の沖縄が出る（`insetShown === false`）／全国表示で枠内の沖縄が出る
- 目ボタンを離すと県名が消える
- コンソールにエラーが出ない
