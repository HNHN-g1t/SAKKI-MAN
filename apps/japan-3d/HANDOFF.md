# 3D日本地図（試作）引継ぎ資料

日本地図タップドリルの地図データ（県の形・座標系）を土台に、標高で起伏をつけた 3D の鳥瞰マップ。
サッ記マン（プレイヤー）をタップで移動させ、山頂に着いたら「絶景を見る」で山頂からの360度ビューに入る。

- 公開URL: https://sakki-man.vercel.app/japan-3d/ （入口のタイトル画面からはまだリンクしていない）
- iOS アプリにはまだ入れていない（`mobile/build_www.py` で除外）

## ファイル

```
japan-3d/
├─ index.html            本体（HTML・CSS・JS を1ファイル。ビルドなし、直接編集）
├─ lib/three.module.min.js  three.js r170（MIT、lib/three-LICENSE.txt）。CDN に頼らずアプリ内でも動くよう同梱
├─ data/
│   ├─ heightmap.webp    標高（可逆 WebP、2120×2380、1画素＝0.5単位≒930m）
│   ├─ borders.json      県境（border）と海岸線（coast）の線分
│   └─ grid.json         ハイトマップの範囲（index.html の GRID と同じ値）
└─ tools/
    ├─ build_heightmap.py  data/ を作る（Python 3 + numpy・Pillow・scipy）
    └─ check3d.js          確認テスト（Playwright）
```

## 座標系（ドリルと同じ）

```
x = (経度 - 128) × cos(36°) × 60     → 3D の X
y = (45.8 - 緯度) × 60                → 3D の Z（北が -Z）
高さ Y = 標高[m] / 1852 × 強調         （1単位 = 緯度1分 = 1.852km）
```

## 標高データ

- 元は AWS の公開標高タイル（Terrarium 形式、ズーム8≒500m）。国土地理院の PNG 標高タイル（cyberjapandata.gsi.go.jp）は作った環境のネットワークで止められていたため。地理院タイルに替えるときは `build_heightmap.py` の `fetch_tile()` と `decode()` を直す
- 陸と海: 標高 > 0 か、ドリルの県の形（`japan-map-quiz/data/paths.json`・`hoppo.json`）の中なら陸。湖は `lakes.json`。朝鮮半島・ロシア沿岸は「国外の陸」として平らなグレー
- 画素の中身: `R*256+G = 標高[m]+12000`（陸は1mきざみ、海の深さは100mきざみ）、`B = 255 日本の陸 / 64 国外 / 128 湖 / 0 海`
- 作り直し: `python3 apps/japan-3d/tools/build_heightmap.py`（タイルは `apps/japan-3d/.tiles/` に保存、git には入れない）
- 500m の解像度なので山頂の細かい形は丸くなる（富士山はデータ上 3701m。カードの標高は正式な値を出す）

## 描画のしくみ

- 地形は 40単位四方のかたまり（27×30）。カメラからの距離で細かさを 64/32/16/8/4 分割から選び、同じ細かさのものを InstancedMesh で一度に描く。重い端末では自動であらくする（`lodBias`）
- 高さはシェーダーでハイトマップ（半精度テクスチャ）から読む → 強調スライダーは作り直しなしで即反映。法線・色（海の深さ→平野→森→岩→雪）も画素ごとに計算
- 霞は距離の2乗の指数。鳥瞰ではカメラの距離に合わせて濃さを変え、絶景ビューでは約200単位（約390km）でほぼ霞む
- 県境・海岸線は線をこまかく分けて地形の高さに沿わせ、遠いほど少し浮かせる
- ラベル（山・国宝世界遺産・絶景ビューの湾や盆地）は HTML。地形にかくれていたら出さない（絶景ビューではうすく）

## 操作

| 操作 | 鳥瞰 | 絶景ビュー |
|---|---|---|
| 1本指ドラッグ／左ドラッグ | 移動（つかんだ地点が指についてくる。はなすと慣性ですべる） | 見回す |
| ピンチ／ホイール | 指の間・カーソルの地点を中心にズーム | 望遠（画角） |
| 2本指ドラッグ／右ドラッグ・Shift+ドラッグ | 上下で傾き、左右・ひねりで回転 | — |
| タップ | その地点（ピンの近くならそのスポット）へサッ記マンが地形に沿って移動。カメラは追従（手で動かすと解除、◎ボタンで再開） | — |

## スポット

`SPOTS`（山頂 21・国宝/世界遺産 6）と `GEO`（湾・湖・盆地・平野・海。絶景ビューで名前と距離だけ）。
`rank` 1 は日本全体でも名前を出す、2 は中くらいの拡大から、3 は近くでだけ。`peak: true` で「絶景を見る」が出る。

## 確認

```
python3 -m http.server 8765        # リポジトリの直下で
node apps/japan-3d/tools/check3d.js  # 別のターミナルで。第2引数にフォルダを渡すとスクショを保存
```

読みこみ・高さ（富士山＞六甲山、強調で比例）・慣性・2本指の傾き・タップ移動・富士山到着→絶景ビュー→もどる・槍ヶ岳から富士山のラベル・コンソールエラーなし。
